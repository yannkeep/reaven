🔴 Indexation de "Brol" & "Test"

Cliquez pour lire ⬇

Critique : Le terme "brol" (désordre/foutoir) et "test" dans l'URL (https://yannkeep.github.io/reaven/brol/room/test/audit/) indiquent clairement que des fichiers brouillons ou des environnements de staging sont indexables par Google.

Action : Mettre en place un fichier robots.txt ou une balise meta "noindex, nofollow" immédiatement sur ces dossiers.

🟠 Profondeur des Liens (Crawl Depth)

Cliquez pour lire ⬇

Critique : Le fichier d'audit est enfoui à 5 niveaux de profondeur (/reaven -> /brol -> /room -> /test -> /audit). Les moteurs de recherche allouent un budget de crawl limité.

Action : Aplatir l'arborescence. Si l'audit est important, il devrait se trouver à /reaven/audit/.

🟠 Absence de Canonicalisation

Cliquez pour lire ⬇

Critique : L'exploration des liens remontants révèle un risque de contenu dupliqué (Duplicate Content) si les dossiers de test contiennent les mêmes informations que le site de production principal.

Action : Définir des balises rel="canonical" pointant vers les versions définitives.
