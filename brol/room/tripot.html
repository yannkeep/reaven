Capacités & Fonctionnalités Clés

Découvrez les principes fondateurs qui font de Saloon un choix robuste pour le développement d'API. Cette section résume les avantages architecturaux extraits de la documentation du dépôt, structurés pour une lecture rapide.

🧱

Orienté Objet

Transforme les appels API complexes en classes PHP propres et réutilisables. Fini les tableaux de configuration infinis, place à l'encapsulation stricte.

🔌

Agnostique au Client

Sous le capot, Saloon peut utiliser Guzzle, Symfony HTTP Client, ou le client de votre choix grâce à un système d'adaptateurs flexible.

🛡️

Authentification Intégrée

Gère nativement les tokens Bearer, Basic Auth, OAuth2, et permet la création d'authentificateurs personnalisés en quelques lignes.

Comprendre l'Architecture

Interagissez avec les onglets ci-dessous pour explorer les trois piliers conceptuels de Saloon. Cette vue interactive permet de décomposer la logique interne du framework sans être submergé par le code.

Le Connecteur (Connector)

Le Connecteur est la classe centrale qui représente l'API tierce avec laquelle vous communiquez (par exemple, Spotify, GitHub, Stripe). Il définit l'URL de base, les en-têtes globaux et les méthodes d'authentification par défaut.

  • Définit la resolveBaseUrl()
  • Applique les defaultHeaders()
  • Gère l'instance du client HTTP sous-jacent
class GitHubConnector extends Connector { public function resolveBaseUrl(): string { return 'https://api.github.com'; } protected function defaultHeaders(): array { return [ 'Accept' => 'application/vnd.github.v3+json', ]; } }

La Requête (Request)

Une Requête représente un point de terminaison (endpoint) spécifique de l'API. Elle définit la méthode HTTP (GET, POST, etc.) et l'URI spécifique.

  • Définit la méthode HTTP via une propriété ou méthode.
  • Définit le point d'accès via resolveEndpoint().
  • Peut encapsuler les données du corps (payload).
class GetUserRequest extends Request { protected Method $method = Method::GET; public function __construct( protected string $username ) {} public function resolveEndpoint(): string { return '/users/' . $this->username; } }

La Réponse (Response)

Saloon renvoie un objet Response riche. Il permet d'accéder facilement au statut HTTP, aux en-têtes et de décoder le contenu JSON en tableaux ou objets (DTOs).

  • $response->json() pour extraire les données.
  • $response->dto() pour un typage fort.
  • Vérifications utiles comme $response->ok() ou $response->failed().
$connector = new GitHubConnector(); $request = new GetUserRequest('ouaisfieu'); $response = $connector->send($request); if ($response->ok()) { $userData = $response->json(); echo $userData['name']; } else { echo "Erreur HTTP : " . $response->status(); }
