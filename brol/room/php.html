L'Architecture d'une Requête

Comment Saloon transforme-t-il votre code orienté objet en une véritable requête HTTP ? Voici le flux de processus simplifié, illustrant la séparation des responsabilités qui fait la force du framework.

🔌

1. Le Connecteur

Définit l'URL de base, les en-têtes globaux et l'authentification partagée pour un service spécifique (ex: API GitHub).

➔
✉️

2. La Requête

Spécifie la méthode HTTP (GET, POST), le point d'accès (endpoint) final et transporte le corps de données (payload).

➔
📥

3. La Réponse

Reçoit le résultat, gère les exceptions, décode le JSON et permet de transformer les données en objets typés (DTOs).
